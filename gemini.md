# PanDao Logistics Website

## Project Goal
Create a premium, modern, and highly interactive landing page for "PanDao Logistics" - a logistics company delivering goods from China to Russia and CIS, with a strong focus on the North Caucasus region (Grozny, Pyatigorsk, Makhachkala, Mineralnye Vody).

## Tech Stack
- **Structure:** Semantic HTML5
- **Styling:** Pure Vanilla CSS (custom properties, Grid/Flexbox, dynamic animations, backdrop filters, responsive layout)
- **Interactions:** Client-side JavaScript (scroll-driven animations, calculator logic, modal forms, interactive tabs)
- **Aesthetic:** Dark-theme high-end editorial & technological vibe (deep obsidian, scarlet accents, clean typography, smooth micro-interactions).

## Architecture & Files
- `index.html` - The main page containing the 9 blocks.
- `index.css` - Design system, global styles, animations, layout.
- `index.js` - Logic for calculator, slider, animations, and forms.
- `DESIGN.md` - Design tokens and visual guidelines.
- `assets/` - Directory for images and SVG icons.
- `assets/logo.svg` - Scalable logo reproduced from the original.
